# Пятилетка — правила проекта

Многопользовательский градостроитель для Roblox: производственные цепочки, логистика, регионы игроков с торговлей.
Дизайн-документ: https://claude.ai/artifact/4YBPUd9Nz95hVmqUGDMHV6
Что сделано, текущий этап и следующие шаги — `docs/PROGRESS.md`. Читай его в начале сессии и обновляй в конце.

## Общение
- С владельцем проекта общаемся по-русски. Комментарии в коде тоже по-русски, идентификаторы — по-английски.
- Владелец новичок в Roblox Studio: объясняй шаги в Studio по пунктам.

## Структура
- `src/shared` → `ReplicatedStorage.Shared`: конфиги (`Config/`) и чистая логика симуляции (`Sim/`).
- `src/server` → `ServerScriptService.Server`: сервисы сервера.
- `src/client` → `StarterPlayer.StarterPlayerScripts.Client`: камера, стройка, интерфейс, визуализация.
- `tests/` — тесты чистой логики на Lune.
- Синхронизация со Studio: Rojo (`default.project.json`). Версии инструментов — `rokit.toml`.

## Правила кода
- Сервер авторитетен: вся экономика считается на сервере, клиент только шлёт команды и рисует.
- Модули в `src/shared/Sim` не трогают Roblox API и не делают `require` других модулей: зависимости передаются аргументами. Так они тестируются в Lune.
- Все числа баланса живут в `src/shared/Config`, не в коде логики.
- `--!strict` в каждом файле.
- Перед коммитом: `stylua src tests`, `selene src`, `lune run tests/run`.

## Чего не делаем
- Не копируем название, графику, интерфейс и тексты Workers & Resources или других игр. Сеттинг — вымышленная Норвальская Республика, без реальных стран, символов и политики.
