## Как появился проект

Владелец хотел перенести в Roblox игру Workers & Resources: Soviet Republic (3Division / Hooded Horse, версия 1.0 вышла 20 июня 2024). Копировать её нельзя: название, графика и интерфейс принадлежат правообладателю, а копию могут снять по жалобе (DMCA). Поэтому делаем **оригинальную игру в том же жанре**: градостроитель с производственными цепочками и логистикой.

## Дизайн коротко

Подробности — в дизайн-документе.

- **Цикл:** добыть → довезти → переработать → потратить или продать → расшириться. Цели задаёт пятилетний план.
- **Цепочки** (на стрелках — ресурсы, которые везут грузовики):
  - лесозаготовка → брёвна → лесопилка → доски → стройплощадки;
  - карьер → гравий → бетонный завод → бетон → стройплощадки;
  - ферма → зерно → пищекомбинат → продукты → магазины;
  - рудник → руда → меткомбинат → сталь → машзавод (выпускает технику). В меткомбинат также нужен уголь;
  - угольная шахта → уголь → ТЭЦ → электричество → все здания (электричество идёт по проводам, его не возят).
- **Логистика:** на старте дороги и грузовики из автопарков, которые сами берут заказы. Дальше по эпохам открываются конвейеры (1), ж/д, автобусы и электросеть (2). Есть склады-хабы и упрощённые пробки. Регионы связывает общая магистраль.
- **Население** считается по домам, а не поштучно. Потребности: жильё, еда, работа (старт), тепло и свет, здоровье (эпоха 2), досуг (эпоха 3). От довольства зависят рост населения и выработка. Загрязнение снижает довольство.
- **Мультиплеер:** биржа сервера с ценами по спросу и предложению, бот «внешнего рынка», контракты между игроками, общие стройки сервера. PvP нет.
- **Прогрессия:** эпохи 0–3 открываются выполнением плана, исследования покупаются за очки плана. Игровой год длится около 20 минут. Офлайн-прогресс ограничен 8 часами и ёмкостью складов. Рейтинги сбрасываются раз в месяц.
- **Архитектура:** сервер авторитетен. Тик симуляции раз в секунду обходит сетку и стройку, логистику, производство, население, биржу и план. Клиент только шлёт команды и рисует. Сохранение региона — DataStore с блокировкой сессии. Цель: тик всех регионов сервера не дольше 20 мс.

- цикл не начинается, если выходной склад полон или не хватает сырья;

- скорость равна `min(1, рабочие / нужно рабочих)`;
- если в конце цикла продукцию некуда сложить, здание ждёт со статусом `output_full`.

## Заметки об окружении

- Облачная сессия может запускать Remote Control на ПК владельца (папка `C:\cl\roblox new game`, клон в подпапке `pyatiletka`). Так проверяется код в Studio: там доступен MCP-сервер Roblox Studio. Git на ПК залогинен в GitHub.
- В облаке скачивание релизов с GitHub заблокировано. Lune и StyLua там собирались через `cargo install`.
- StyLua 0.20.0 на ПК трижды находил строки длиннее 110, которые в облаке «проходили». Настоящая причина: в облаке StyLua был собран `cargo install stylua` без фичи `luau` и молча пропускал файлы `.luau`. Собирать так: `cargo install stylua --version 0.20.0 --locked --features luau`. Ширина считается в байтах UTF-8 (кириллица — 2 байта), поэтому строки с русским текстом переносятся раньше, чем кажется. Ещё: StyLua 0.20.0 с `--features luau` падает на длинных строках с оператором `//`, поэтому вместо `a // b` пишем `math.floor(a / b)`.
