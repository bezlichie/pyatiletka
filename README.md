# Пятилетка

Градостроитель для Roblox про промышленность и логистику: у каждого игрока свой регион, производственные цепочки и торговля с соседями по серверу.

## Первый запуск (Windows)

1. Установите [Rokit](https://github.com/rojo-rbx/rokit) — менеджер инструментов.
2. В корне репозитория выполните `rokit install`: поставятся Rojo, Lune, StyLua, Selene и Wally нужных версий.
3. Поставьте плагин Rojo в Studio: `rojo plugin install`.
4. Запустите сервер синхронизации: `rojo serve`.
5. В Studio откройте пустой Baseplate, вкладка **Plugins → Rojo → Connect**.
6. Нажмите **Play**. В Output должно появиться `[Пятилетка] сервер запущен`, а каждые 10 секунд — отчёт лесозаготовки.

## Команды

| Что | Команда |
| --- | --- |
| Синхронизация со Studio | `rojo serve` |
| Тесты логики | `lune run tests/run` |
| Форматирование | `stylua src tests` |
| Линтер | `selene src` |
